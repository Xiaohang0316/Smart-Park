# 智慧园区数字孪生平台 (Demo)

根据 `1.md` 需求开发的智慧园区数字孪生可视化 Web 应用原型,当前完成**第一阶段 MVP**(园区总览三维场景 / 空间钻取 / 图层叠加 / 停车场 / 数据看板)。

## 快速开始

```bash
npm install     # 若本机 ~/.npm 缓存损坏, 可加 --cache /tmp/npm-cache
npm run dev     # http://localhost:5173
npm run build   # 类型检查 + 生产构建
```

## 技术栈

| 领域 | 选型 |
| --- | --- |
| 框架 | React 18 + TypeScript + Vite |
| 三维 | Three.js(OrbitControls / CSS2DRenderer / Canvas 程序化纹理) |
| 状态 | Zustand |
| UI | Tailwind CSS + shadcn 风格组件(手写) |
| 图表 | ECharts 5 |
| 数据 | 本地 Mock + `setInterval` 模拟 IoT 推送 |

## 已实现功能(第一阶段 MVP)

1. **园区总览三维场景** — 6 栋楼宇(窗格纹理)、道路网格、绿化树丛、中央广场喷泉、3D 停车场;鼠标拖拽旋转/缩放/平移;昼夜模式平滑切换(灯光/天空/窗格自发光/星星)
2. **空间钻取导航** — 点击楼宇相机飞行动画聚焦;点击楼层号**相机直接飞入楼层内部**(楼体外壳半透明, 展示楼板/房间色块/半高隔断/办公家具/会议室/卫浴/设备间/结构立柱/电梯核心/吊顶灯带/室内绿植, 可自由漫游);侧边栏 楼宇列表 → 楼层列表 → 楼层概览 + 房间列表(点击在 3D 中高亮);面包屑(园区 > A栋 > 3楼)逐级返回
3. **图层叠加系统** — 人流热力(颜色随入驻率变化 + 脉冲)、车流状态(粒子沿道路运动)、告警点位(光柱闪烁)、绿化图层,右侧工具栏独立开关
4. **停车场模块** — 2D 车位平面图(空闲绿/占用红/预约黄/故障灰)、点击弹详情卡(编号/车牌/剩余时间倒计时)、反向寻车(输入车位号 → 高亮 + 动画路径线)、3 秒实时状态刷新
5. **数据看板** — KPI 指标卡(数字滚动)、24h 人流折线(实时追加)、楼宇能耗柱状、告警类型环图、实时告警列表

## 模拟实时数据流

`src/data/mockStream.ts` 用 `setInterval` 模拟 IoT 推送(3s 车位状态 / 2s 人流 / 6s 概率告警),替换真实后端时改此文件接入 WebSocket/SSE 即可。

## 目录结构

```
src/
├── types/           # 数据结构定义(Building/Floor/ParkingSpot/Alert...)
├── data/            # Mock 数据生成 + 实时流模拟
├── store/           # Zustand 全局状态
├── three/           # Three.js 引擎(场景构建/拾取/飞行/昼夜/图层)
├── components/
│   ├── ui/          # shadcn 风格基础组件
│   ├── layout/      # 顶栏
│   ├── overlays/    # 面包屑/钻取面板/图层工具栏/告警流
│   └── charts/      # ECharts 封装
├── pages/           # 园区总览 / 停车场 / 数据看板
└── hooks/ lib/      # 数字滚动 Hook / 工具函数
```
